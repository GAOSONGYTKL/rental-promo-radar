Which payment route do the official pages describe?

The general Hertz Pay Now page says prepaid rates cannot be combined with promotional offers. It also says a CDP can be added, but a negotiated rate can make retail prepayment unavailable. This is not a promise that every CDP works with Pay Now.

What should I record before comparing routes?

Make a route card before opening a second search. Record the official offer address, review date, payment label, booking deadline, pickup deadline and participating region. These entries describe an offer rather than prove that your trip qualifies. Leave an unstated deadline marked unstated. A month in an article heading is not a substitute for a deadline in the offer terms.

How do I keep the comparison meaningful?

Create separate records for the public Pay Later quote, a qualifying partner Pay Later quote and an official Pay Now promotion. Keep pickup and return offices, dates, times, car group and driver details identical. Copy the final displayed amount and cancellation terms for each route. If a car group changes, flag that row as unmatched instead of treating its lower price as a saving.

Where does a code belong in the record?

Write the code label exactly as the official offer identifies it. Keep a CDP and a promotion code in separate cells when the source specifies both. Do not move numbers between cells just because a coupon directory uses one umbrella term. Mark source, field and eligibility as three separate checks; a valid identifier is only one part of the decision.

How should I handle conflicting conditions?

When a general policy and an individual offer appear inconsistent, save both source addresses and the relevant conditions. Treat the selected offer as a question to resolve, not permission to stack promotions. Ask Hertz which terms govern the exact reservation before payment. Keep the answer with the route card. Do not cancel an existing prepaid booking merely to experiment with a different code.

What does the result actually prove?

Calculate a displayed cash difference only between matched final totals: comparison-route total minus chosen-route total. Every input must come from your actual reservation summaries. Do not subtract a guessed value for reward points, upgrades or future waivers. An unavailable route stays unavailable in the worksheet; it is not a zero-price alternative. A lower total today proves only what that particular search displayed.

What is the stop rule?

Stop when an eligibility condition, payment label or mandatory charge remains unresolved. Save the quote without submitting a purchase and ask the provider a narrow question about the missing item. Recheck the conditions before paying. Our route card is an original evidence-organizing method, not a booking experiment or a guarantee that any offer will be cheaper.

Can I assume a code is stackable?

No. The two specific offers reviewed here prohibit combining them with other promotions. Use the conditions attached to the route you select, not a blanket claim about every Hertz discount code.

Which should I check first: the code or payment route?

Read the payment route in the specific official offer first, then match its code requirements. A Pay Later-only offer does not become a prepaid offer because its code was accepted.
