Apply the official offer

  1. Open the Dollar offer above and enter your real location and dates.
  2. Choose Pay Now during booking.
  3. Review the selected rate, cancellation conditions and final total before confirming.

This advertised saving is against the Pay Later base rate, not the complete bill. No coupon is supplied on the offer page. Do not invent a code to claim it.

Keep the comparison honest

A prepaid quote and a later-payment quote are two different payment products. Keep your itinerary, vehicle group and extras fixed when comparing them, and label the payment choice beside each total. If cancellation conditions differ, retain that difference instead of presenting the lower number as an identical order.

A missing saving does not establish that a coupon failed: this route does not supply one. First identify whether the selected price is actually Pay Now. Then separate an excluded itinerary from an eligible trip whose displayed saving differs. These are different questions to take to support.

A partner page lists two different promotion codes

Southwest’s Dollar instructions list Corporate Discount 3055251 with Promotion Code 101611. Its terms instead require Promotion Code 102355 alongside that same corporate number and a Rapid Rewards number. The page offers a prefilled booking route and limits the discount to Pay Later base rates.

Read the official partner instructions and terms

Neither promotion code is verified here as working. The disagreement is in the published source before any order has been tested. A booking engine rejecting a code would be a separate observation; do not claim that happened from this text comparison alone.

Keep four pieces of evidence together: the instructions, the terms, the code actually shown by the booking route, and the final quote for your unchanged trip. Ask the provider which promotion applies to that reservation if these disagree. Trying both numbers and accepting whichever produces a lower amount would not resolve whether the reservation meets the intended offer.

Check restrictions after choosing a route

  • Payment: the Dollar card above uses Pay Now; the named Southwest partner discount uses Pay Later.
  • Location and vehicle: check participating locations and the selected rate’s eligibility.
  • Time: distinguish advance notice, rental length and pickup deadline.
  • Combination: the Pay Now offer excludes other discounts, promotions and special rates.

Do not transfer a condition between these routes merely because both advertise a Dollar saving. Write the offer name beside every condition you check. If you change the trip to meet a restriction, save that as a separate alternative rather than overwriting your original comparison.

Questions before paying

Where do I enter a Dollar rental coupon code?

The current official booking widget has an “Add a Discount” control. The Pay Now offer above instead tells you to select Pay Now; it does not provide a coupon to enter.

Is the biggest percentage the cheapest order?

Not necessarily. Compare final totals for matched trips and retain differences in payment and cancellation conditions. A base-rate percentage alone cannot establish the cheapest complete order.

Should I use the partner code from its instructions or its terms?

This review cannot settle that conflict. Use the named official route, check the applied offer and seek reservation-specific clarification before relying on it. An unresolved code is not a verified discount.
